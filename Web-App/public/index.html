Security and Privacy

Security

  • Secure Login Authentication — The system ensures that users can only log in using valid registered credentials.
  • Password Protection — User passwords are protected and should not be displayed or stored as plain text.
  • Email OTP Verification — The system uses a One-Time Password (OTP) sent to the user’s registered email address to provide an additional layer of account security.
  • Login Attempt Protection — The system limits repeated failed login attempts to help prevent unauthorized access.
  • Session Security — Active login sessions are protected, and users may be required to log in again when their session expires.
  • Input Validation — The system validates information entered into the login form to prevent invalid or potentially harmful inputs.

Privacy

  • Personal Information Protection — User information, such as names, email addresses, and account credentials, is protected.
  • Limited Data Collection — The system collects only the information necessary for user authentication and system functions.
  • Authorized Access — Sensitive user information can only be accessed by authorized users or administrators.
  • Data Confidentiality — Users’ personal information should not be shared with unauthorized individuals.
  • Secure Data Storage — User information is stored securely in the database with appropriate access restrictions.
  • Privacy Policy — The system informs users about what information is collected, how it is used, and how it is protected.
